A³ FinCanvas

An interactive, client-side budget planner built with HTML, CSS and JavaScript. Plan your income and expenses, explore "what-if" scenarios, and see your money visualised with charts, all in the browser with no backend required.

Formerly known as A^3 Budgetly. Developed by A³ Webworks as a project for CSE326: Web Development at Lovely Professional University.

Features
Budget planning: enter your income and expenses by category and see where your money goes.
Student mode: a simplified view tailored to student budgets (allowance, rent, food, travel, subscriptions and so on).
What-if analyzer: change income or spending values and instantly see how savings and balance would change.
Charts and visualisations: interactive charts powered by Chart.js.
Fully client-side: runs entirely in your browser, with no server and no sign-up.
Responsive design: works on desktop and mobile screens.

How to Use

1.Enter your income and monthly expenses.
2.Toggle Student Mode if you want student-focused categories.
3.Review the charts to see your spending breakdown.
4.Open the What-if analyzer and tweak values to test different scenarios.
